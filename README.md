# Portfolio-Tracker
A simple stock portfolio tracker with unified summary in one currency.

Also includes international news and Indonesia news

<img width="2864" height="1623" alt="image" src="https://github.com/user-attachments/assets/92325984-5073-49e7-8108-56f8f06e81d6" />


## Features
+ Search to add stock to holding
+ Edit holding average buy and quantity
+ Stock holding weight compared to total equity
+ International news and Indonesia news
+ Summary of holdings
